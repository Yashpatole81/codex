# FlowForge Frontend

Current status: minimal Next.js App Router starter with dark-mode defaults.

## Run locally

```bash
cd flowforge-frontend
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Included now

- Next.js app shell (`app/layout.tsx`, `app/page.tsx`)
- Global dark theme tokens matching FlowForge palette
- Starter scripts for dev/build/start/lint
